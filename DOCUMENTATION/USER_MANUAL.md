## Introduction

### What is OJT360?
OJT360 is a comprehensive On-the-Job Training Management System designed to streamline the OJT process for students, coordinators, supervisors, and administrators.

### System Roles
- **Student (Intern)** - OJT participant
- **Coordinator** - Academic supervisor managing students
- **Supervisor** - Company supervisor overseeing interns
- **Admin** - System administrator

## Getting Started

### 1. Account Creation & Login

#### Students (Whitelist-Based Activation)

**IMPORTANT**: Your coordinator must upload a class list first before you can activate your account!

1. **Go to Activation Page**
   - Visit the OJT360 student activation page
   
2. **Enter Your Student ID**
   - Input your school-issued Student ID
   - Click "Send Verification Link"

3. **Check Your Email**
   - System sends verification link to your school email (@evsu.edu.ph)
   - Email address comes from the class list uploaded by your coordinator
   - Link expires in 60 minutes

4. **Click Verification Link**
   - Opens registration form with pre-filled information:
     - Name (from class list)
     - Email (from class list)
     - Student ID (from class list)
     - Department & Program (from class list)

5. **Complete Registration**
   - Set your password (minimum 8 characters)
   - Confirm password
   - Enter phone number
   - Enter address
   - Select year level
   - Select section
   - Click "Complete Registration"

6. **Auto-Login**
   - Account created and email auto-verified
   - Redirected to dashboard

**If Link Expired:**
- Go back to activation page
- Re-enter your Student ID
- New link will be sent

**Troubleshooting:**
- "Student ID not found" = Coordinator hasn't uploaded class list yet or your ID is not in the list
- Contact your coordinator to add you to the class list

#### Coordinators (Invitation-Based)

1. **Receive Email Invitation**
   - Admin sends invitation to your email
   - Email contains secure registration link
   - Link expires in 1 hour

2. **Click Invitation Link**
   - Opens registration form with:
     - Email (pre-filled, read-only)
     - Department (pre-assigned)
     - Program (pre-assigned)

3. **Complete Registration**
   - Enter your full name
   - Enter employee ID
   - Enter phone number
   - Set password (minimum 8 characters)
   - Confirm password
   - Click "Complete Registration"

4. **Auto-Login**
   - Email automatically verified
   - Coordinator profile created
   - Redirected to coordinator dashboard

**If Link Expired:**
- Visit the expired link page
- Click "Resend Invitation"
- Enter your email
- New link will be sent

#### Supervisors (Self-Registration or Invitation)

**Option A: Invitation from Coordinator**
1. Coordinator sends invitation
2. Receive email with registration link
3. Click link and complete registration
4. Set password
5. Email auto-verified

**Option B: Self-Registration**
1. Visit supervisor registration page
2. Enter company email
3. Verify email through link
4. Complete registration form
5. Provide company details

### 2. First Login
1. Go to: `http://your-domain.com`
2. Click **Login**
3. Enter email and password
4. Click **Sign In**

### 3. Password Reset
1. Click **Forgot Password?** on login page
2. Enter your email
3. Check email for reset link
4. Click link and set new password

## Student Guide

### A. Dashboard Overview
Your dashboard shows:
- OJT Status (Not Started/Active/Completed)
- Completed Hours vs Required Hours
- Progress percentage
- Recent activities
- Today's attendance status

### B. Pre-Placement Process

#### Step 1: Submit Required Documents
1. Go to **Documents** → **Pre-Placement**
2. Required documents:
   - Application Letter
   - Resume/CV
   - Personal Data Sheet (PDS)
   - Medical Certificate
   - Parent's Consent
   - Barangay Clearance
   - NBI Clearance (if required)

3. For each document:
   - Click **Upload** button
   - Select PDF/DOCX file
   - Add notes (optional)
   - Click **Submit**

4. Wait for coordinator approval

#### Step 2: Get Acceptance Letter
1. After documents approved, find company
2. Submit application
3. Wait for supervisor acceptance
4. Acceptance letter appears in your dashboard

#### Step 3: MOA (Memorandum of Agreement)
1. Wait for coordinator notification
2. Receive "MOA Ready" notification
3. Contact coordinator to collect MOA

#### Step 4: OJT Activation
1. After all steps complete
2. Coordinator activates your OJT status
3. You can now start logging attendance

### C. Daily Attendance

#### Time In
1. Go to **Attendance** page
2. Click **Time In** button
3. Confirm your action
4. System records time with IP address

#### Time Out
1. Return to **Attendance** page
2. Click **Time Out** button
3. Confirm your action
4. System calculates hours worked

#### Attendance Recovery
If you forgot to time out:
1. Find incomplete log in dashboard
2. Click **Complete** button
3. Enter actual time out
4. Provide reason
5. Submit for coordinator approval

### D. Weekly Reports

#### Submitting Weekly Report
1. Go to **Reports** → **Weekly Reports**
2. Click **Submit New Report**
3. Fill out form:
   - Week number
   - Tasks accomplished
   - Skills learned
   - Hours worked (auto-filled)
4. Click **Submit**
5. Wait for coordinator review

### E. Monthly Evaluations
1. Supervisor submits evaluation
2. You receive notification
3. View evaluation in **Evaluations** → **Monthly**
4. Review ratings and comments

### F. Final Evaluation
1. At OJT completion, supervisor submits final evaluation
2. Coordinator reviews
3. You receive notification
4. Download PDF copy from **Evaluations** → **Final**

### G. Messages
1. Go to **Messages**
2. Click **Compose** to send message
3. Select recipient (Coordinator/Supervisor)
4. Write subject and message
5. Click **Send**

### I. Upload Class List (CRITICAL - Do This First!)

**IMPORTANT**: Students CANNOT activate their accounts until you upload the class list!

#### Why Upload Class List?
- Creates enrollment whitelist for your program
- Students verify their identity using Student ID
- System sends activation links to school emails from the list
- Prevents unauthorized registrations

#### Step-by-Step Upload Process

1. **Prepare Excel/CSV File**
   - Required columns:
     - **Student ID** (e.g., 2020-12345)
     - **Student Name** (Last, First Middle format)
     - **E-Mail** (must be @evsu.edu.ph)
     - **Phone** (optional: contact number)
   
2. **Go to Students → Import Class List**
   
3. **Download Template (Optional)**
   - Click "Download Template"
   - Use as reference for correct format

4. **Upload File**
   - Click "Choose File"
   - Select your Excel (.xlsx, .xls) or CSV file
   - Click "Preview Import"

5. **Review Preview**
   - System shows:
     - ✅ Valid rows (will be imported)
     - ❌ Invalid rows (with error reasons)
   - Check for:
     - Duplicate Student IDs
     - Invalid emails
     - Missing required fields

6. **Fix Errors (if any)**
   - Download errored rows
   - Correct issues in your file
   - Re-upload

7. **Confirm Import**
   - If all rows valid, click "Import All Students"
   - System creates enrollment whitelist
   - Students can now activate accounts

#### View/Manage Whitelist

1. **Go to Students → Class List Status**
2. **See All Imported Students**
   - Status: Pending (not activated) or Activated (account created)
   - Search by Student ID, Name, or Email
   - Filter by status

3. **Export Class List**
   - Click "Export to CSV"
   - Download current class list

4. **Download Original Uploaded File**
   - Click "Download Uploaded File"
   - Get the original file you imported

5. **End of Term Archive**
   - At end of semester/year
   - Click "Archive for End of Term"
   - Moves all records to archived status
   - Prepares for next batch of students

#### Updating Class List

**To replace entire class list:**
1. Upload new file
2. System automatically replaces old pending records
3. Already activated students remain unaffected

**To add individual students:**
-current file
2. Add new student rows
3. Re-upload file
4. New students added, existing remain

## Troubleshooting

### Can't Login
- Check email and password
- Try password reset
- Ensure email is verified
- Contact admin if issue persists

### Document Upload Failed
- Check file size (max 5MB)
- Use supported formats (PDF, DOCX)
- Try different browser
- Check internet connection

### Time In/Out Not Working
- Enable location services
- Check internet connection
- Try refreshing page
- Contact coordinator

### Not Receiving Notifications
- Check email spam folder
- Verify email address in profile
- Check notification settings
- Contact admin
